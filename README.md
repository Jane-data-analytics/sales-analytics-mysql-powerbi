 sales-analytics-mysql-powerbi
Sales data cleaning and analysis using MySQL, with an interactive Power BI dashboard.

 **Project Overview**
This project analyzes sales data using MySQL for data cleaning and SQL-based analysis, followed by an interactive Power BI dashboard to explore sales performance.

 **Tools & Technologies**
- MySQL
- SQL
- Microsoft Power BI
- DAX and Data Visualization

 **Project Workflow**
1. Created a working copy of the raw sales data.
2. Identified and removed duplicate records.
3. Standardized inconsistent date formats and converted dates into the DATE data type.
4. Cleaned text fields and handled missing or invalid values.
5. Calculated total sales revenue using quantity and unit price.
6. Performed sales analysis using aggregate functions, CTEs, window functions, and LAG().
7. Built an interactive Power BI dashboard for sales performance reporting.

 **SQL Analysis**
- Total sales records and quantity sold
- Total revenue and average unit price
- Product-level revenue analysis
- Top-performing products
- Product contribution to total revenue
- Cumulative sales revenue over time
- Month-over-month revenue growth

 **Power BI Dashboard**
The dashboard includes three report pages:
-Sales Overview: Key performance indicators and monthly revenue trends
- Product Overview: Product performance and revenue comparisons
- Sales Target vs Actual:Monthly target comparison and sales difference

Interactive date slicers and page navigation support report exploration.

 **Repository Files**
- `01_data_cleaning.sql` — Data cleaning and preparation
- `02_sales_analysis.sql` — SQL analysis queries
- `screenshots/` — Dashboard screenshots (to be added)

 **Key Skills Demonstrated**
SQL data cleaning, data standardization, data analysis, CTEs, window functions, revenue analysis, Power BI reporting, and dashboard design.

 **Data Source**
The project uses a sales dataset originally obtained from Kaggle. The dataset was used for SQL-based data cleaning, sales analysis, and Power BI dashboard development.
